Proteja seu progresso local.

Backups SQLite verificados, exportação JSON completa e restauração segura sem enviar dados para a nuvem.

SQLite

Backup automático e manual

O SIDES cria backup automático quando o último estiver antigo, valida o arquivo e mantém uma rotação limitada.

Portabilidade

Exportar ou importar JSON

O JSON V9 inclui todas as tabelas do SIDES. Antes de importar, o sistema cria automaticamente um backup de segurança.

Recuperação

Restaurar banco SQLite

Uma restauração é primeiro validada e preparada. O banco em uso não é substituído durante a sessão. Depois de preparar a restauração, feche e abra novamente o SIDES para aplicá-la.

Privacidade operacional

Logs locais com retenção

Os logs registram somente eventos técnicos de integridade, backup, importação e restauração. Não registram respostas de estudo, textos escritos, transcrições ou áudio. A retenção padrão é de 30 dias.
